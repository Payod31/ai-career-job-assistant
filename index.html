Add a role above (or upload a resume) and click Build my search links. Each board card shows exactly which filters its link carries — boards do not all accept the same filters.

How this works — read this once
  • These are pre-filled external searches, not listings fetched by this app. No vacancies, salaries or companies are invented — open a link to see live postings, then copy a JD into the Job Description tab to run a Match Analysis.
  • Boards handle filters differently: each card below the results shows exactly what its links pass (keywords, location, experience) and what they don't. Salary is a page-level filter only — apply it after opening the board.
  • Live, aggregated listings are not wired in yet. A real listing source would need an authorized job API; none is integrated, and nothing here simulates one.
  • Also worth knowing: Surely Remote is a specialist board for remote roles — set the location filter to Remote and open any of the board links, or browse Surely Remote directly.
